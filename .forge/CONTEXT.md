# Paseo Agent Team

하나의 Paseo 프로젝트 안에서, 역할별로 다른 provider/모델을 쓰는 에이전트들을 오케스트레이터가 지휘하는 구조를 다룬다.

## Language

**프로젝트 (Project)**:
Paseo에 등록된 실제 레포 하나(`prj_…`). 오케스트레이션의 범위다.
_Avoid_: 팀, 그룹

**워크스페이스 (Workspace)**:
프로젝트 안의 Paseo 내장 workspace(`wks_…`). 팀의 에이전트들이 놓이는 자리다. 한 팀은 오케스트레이터의 워크스페이스 하나만 쓰고, 모든 역할이 그 안에서 돈다.
_Avoid_: 봇, 슬롯

**역할 (Role)**:
사용자가 정의한 책임과 로컬 prompt 파일의 묶음이며, 여러 팀원이 같은 역할을 맡을 수 있다. 모든 역할 세션은 팀의 워크스페이스에서 돈다.
_Avoid_: 페르소나, 봇

**오케스트레이터 (Orchestrator)**:
한 워크스페이스에서 돌며, 그 워크스페이스의 팀 정의를 읽고 역할들에게 일을 나눠 맡기는 에이전트. 한 프로젝트에 여러 개가 있을 수 있다.
_Avoid_: Chief of Staff, 리더, 매니저

**역할 세션 (Role session)**:
한 역할을 맡아 워크스페이스 안에서 도는 에이전트 하나. 같은 워크스페이스에 여러 역할의 세션이 함께 있을 수 있다.
_Avoid_: 탭, 봇

**팀 정의 (Team definition)**:
프로젝트 레포 안에 저장되어 git으로 관리되는, 팀 하나의 역할 목록 원본. 오케스트레이터 워크스페이스 하나에 속하며, 워크스페이스마다 파일 하나(`.agents/teams/`)를 둔다.
_Avoid_: 로스터, 팀 설정

**팀원 (Team member)**:
팀 정의의 고유한 memberId와 Role 참조, 사용자가 선택한 Agent Profile의 시작 설정 스냅샷을 가진다. 팀원마다 재사용하는 Role session 하나를 두며, 세션을 초기화해도 memberId는 유지한다. Orchestrator는 구체적인 팀원 하나를 가리킨다.
